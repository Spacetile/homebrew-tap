# Spacetile Homebrew tap

```bash
brew install --cask spacetile/tap/spacetile
```

Spacetile updates itself through Sparkle, so the cask sets `auto_updates true` and `brew upgrade` leaves it alone. This tap only carries Stable releases; pick Beta or Nightly in Spacetile's Settings → General.

Docs: [spacetile.app](https://spacetile.app/docs/). Issues: [Spacetile/Spacetile.app](https://github.com/Spacetile/Spacetile.app/issues).
